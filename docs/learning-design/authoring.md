# Applying the pattern to another chapter

## Before drafting

1. State the capability in an observable sentence. For interpretive chapters, use criteria for defensible reasoning rather than one preferred political or commercial conclusion.
2. List prerequisites and a short way for readers to recognise a gap.
3. Inventory claims by section. Keep dates, actors, units, exceptions, and source locators. Distinguish primary evidence, an attributed argument, a forecast, and an invented example.
4. Inspect the source passage before strengthening a claim. Record unavailable or partial evidence and decide whether to qualify, defer, or remove the claim from assessment.
5. Draft the task and feedback before adding explanatory prose.

## Compose for the task

- Explain one distinction at a time, then show its use in a concrete example.
- Label invented facts. Use current real examples only where their currency matters and their sources can be checked.
- Put an attempt before its answer. Use native expandable feedback so the reader controls disclosure.
- Make interpretive feedback describe evidence, reasoning, counterarguments, and uncertainty. Do not grade agreement with the author.
- Include a brief return to an earlier concept. Keep optional reading separate from what is needed to attempt the task.
- Use meaningful headings, explicit table headers, text alternatives, and links that name their destination. Check the actual browser experience, including keyboard use and narrow screens.

## Maintain traceability

Keep existing section IDs where their purpose survives. Update the curriculum map when learning intent changes. Map source items to taught, referenced, deferred, excluded, or unresolved, with a reason for omissions.

Change a quiz's storage ID when its questions change materially, so old scores do not describe a new assessment. Saved completion remains a reader's personal record; do not reinterpret it as demonstrated competence.

Record source version and inspection date separately from event date. A linked paper's abstract supports only what it states; a full-paper or independent evaluation claim requires that work. Public access does not establish reuse permission.

## Review before expanding

Read the actual output against the source map. Check that a reader can attempt the task using the provided preparation and receive useful feedback. Run local structural checks and use the browser for interactions and layout.

For the learner pilot, ask intended readers to attempt the release assessment before and after reading, explain their reasoning, and find one supporting source. Note confusion, unsupported conclusions, navigation failures, and elapsed time. Use those observations to revise; a small convenience pilot does not establish causal effectiveness.
